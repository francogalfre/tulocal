# tutienda — agent config

Instructions for coding agents live in the root `AGENTS.md` and in `.claude/`, not here. This file exists only so a tool that scans `.agents/` for config finds a pointer instead of nothing.

- `../AGENTS.md` — stack, repo layout, commands, and code-quality rules.
- `../CLAUDE.md` — Claude Code entry point, imports `AGENTS.md` and `.claude/CONTEXT.md`.
- `../.claude/CONTEXT.md` — what the product is, who it's for.
- `../.claude/DESIGN.md` — visual design system and voice/tone rules.
- `../.claude/RULES.md` — behavior spec for the shop's AI sales agent.
